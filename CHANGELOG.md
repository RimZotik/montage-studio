# Changelog — Montage Studio

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [Не выпущено]

## [0.3.0] — 2026-11-01

Проект как рабочее пространство.

### Добавлено

- Открытый проект: вкладки «Подготовка · Монтаж · Экспорт», имя проекта в заголовке окна, «Файл → Закрыть проект» (Ctrl+W); новый проект открывается сразу после создания.
- «Подготовка»: название проекта и последовательность (размер кадра — пресеты и свои значения, частота, фон); медиа и правила — места под 0.5.
- Сервис проекта в ядре: проверка правок, атомарная запись, история с отменой и повтором (Ctrl+Z, Ctrl+Shift+Z, кнопки во второй строке), миграция старых файлов, отказ открывать файлы новее приложения.
- Вкладка «Проекты»: таблица всех проектов (формат, когда открыт и создан, папка), открыть, показать в папке, убрать из списка.
- Лимиты Claude обновляются сами при запуске, если данным больше 15 минут.

## [0.2.0] — 2026-11-01

Компоненты одной кнопкой и тихие обновления.

### Добавлено

- Установка Node.js 24.22.2 и ffmpeg 9.0.2 из «Готовности» на главной: загрузка с докачкой после обрыва, проверка SHA-256, распаковка и подмена одним шагом; ход, отмена, понятные ошибки; после установки — перепроверка.
- Тихое автообновление: проверка после запуска и раз в 30 минут, установщик скачивается в фоне, «Обновить до X» во второй строке и в меню «Справка», установка без окон.
- Скрипт выпуска `scripts/release.mjs`: сборка с подписью, `latest.json`, публикация в GitHub Releases.
- Ошибки в любом потоке пишутся в журнал.

## [0.1.0] — 2026-11-01

Каркас приложения и главная.

### Добавлено

- Окно на весь экран без системной рамки: системная строка меню (Файл, Правка, Вид, Окно, Справка), строка страницы (Главная, Проекты, Библиотека, поиск, лимиты Claude, «Новый проект»), строка состояния.
- Реестр команд: меню, горячие клавиши (не зависят от раскладки), палитра команд `Ctrl+Shift+P`.
- Главная: «Начать», готовность системы (Claude Code, Node.js, ffmpeg, ffprobe — версия или «Как установить»), железо ПК, недавние проекты с фильтром по формату и поиском, пропавшие папки с «Убрать из списка», счетчики.
- Новый проект: название, папка, формат (вертикальный, горизонтальный, квадрат), частота кадров; каркас папки проекта (`project.json`, `timeline.json`, `rules/`, `media/`, `smart/`, `output/`). Открытие папки проекта.
- Лимиты Claude (сессия 5 часов и неделя) с временем сброса; обновление по кнопке коротким запросом.
- SQLite приложения с миграциями: недавние проекты, последние лимиты.
- Языки ru и en, переключение без перезапуска.
- Скрытые правила студии для Claude (`src-tauri/resources/claude/core-rules.md`).
- Просмотр интерфейса в браузере с образцами данных (`npm run dev`).
