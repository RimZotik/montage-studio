# CLAUDE.md — Montage Studio

Правила работы в репозитории. Как устроено приложение — в `docs/` (карта в `README.md`).

## Общее

- Стек: Tauri 2 + Vite + TypeScript + React (интерфейс), Rust (ядро), Remotion (сборка видео),
  ffmpeg (медиа). Подробно — `docs/architecture.md`.
- Проект независимый: в коде, документах, макетах и примерах — нейтральные данные, без отсылок к
  другим продуктам и проектам владельца.
- Без «сделано как у X» и упоминаний сторонних программ в документах, комментариях и коммитах —
  удобство общепринятых монтажных программ берем как идею, не как копию (код, иконки, тексты,
  оформление — свои).
- Интерфейс на двух языках (ru, en) с первого экрана: любой видимый текст — через ключи
  перевода, оба файла обновляются в той же правке.
- В интерфейсе без эмодзи — только иконки `lucide-react`; иконка рядом с текстом — по центру по
  вертикали.
- Любое действие пользователя — команда реестра команд (`docs/ui.md`): меню, горячие клавиши,
  контекстные меню, палитра команд и Claude вызывают одно и то же.
- Файл проекта меняется только через сервис проекта в Rust (история, отмена, проверка схемы) —
  ни интерфейс, ни Claude не пишут его напрямую.
- Данные на диске — с полем `version` и миграцией при чтении; SQLite — миграции по
  `PRAGMA user_version`.
- Версии 0.Y до MVP 1.0 (`docs/roadmap.md`); номер версии — в `Cargo.toml`, `package.json`,
  `tauri.conf.json` одинаковый.

## Проверки

- Rust: `cargo test`, `cargo clippy --all-targets -- -D warnings`.
- Интерфейс: `npm run typecheck`, `npm test`; вид — `npm run dev` в браузере (образцы данных,
  `src/shared/ipc/browserMock.ts`) или `npm run tauri dev`.
- Скрытые правила для Claude — `src-tauri/resources/claude/core-rules.md` (английский, коротко;
  пользователю не показываются, `docs/assistant-layer.md`).
- Изменения интерфейса — смотреть запущенное приложение (снимок экрана), не только тесты.

## Документация

- `README.md` — вход и оглавление; `docs/<тема>.md` — по файлу на часть; `CLAUDE.md` — только
  правила; `CHANGELOG.md` — изменения версий (с первой версии).
- Шаблон файла в `docs/`: `# Название` и одна-две строки, затем `## Назначение`,
  `## Как устроено`, `## Данные и хранение`, `## Правила`, `## Связанное`.
- Изменил часть — обнови ее docs-файл в той же правке; новая часть — новый файл и строка в
  оглавлении `README.md`. Одно знание — в одном месте. Без значений секретов.
- Макеты — `design/mockups/*.html` (открываются в браузере без сборки).
- Файлы документации не называть `claude.md` в любом регистре: в Windows он совпадает с
  `CLAUDE.md` и читается как файл правил (связь с Claude — `docs/claude-bridge.md`).
