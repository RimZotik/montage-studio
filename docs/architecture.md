# Устройство приложения

Как разделены интерфейс, ядро на Rust, внешние компоненты и Claude; стек и раскладка папок.

## Назначение

Приложение — монтажный стол, где ролик правят двое: человек в интерфейсе и Claude Code через
инструменты студии. Источник правды один — файл проекта; рендер собирает видео по нему.

## Как устроено

```
┌──────────────── Окно (WebView, React) ────────────────┐
│ меню · рабочие области · панели · таймлайн · чат      │
│            ▲ команды и события (tauri-specta)         │
└────────────┼──────────────────────────────────────────┘
┌────────────┴──────────── Ядро (Rust) ─────────────────┐
│ сервис проекта (история, отмена, схема)               │
│ сервис Claude (процесс claude, разбор потока событий) │
│ терминал (pty) · MCP-сервер студии (localhost)        │
│ менеджер компонентов · медиа (ffprobe, миниатюры)     │
│ очередь рендера                                       │
└──────┬──────────────┬───────────────┬─────────────────┘
       │              │               │
  claude CLI     Node.js + движок   ffmpeg / ffprobe
  (у пользователя) рендера (Remotion) (компонент)
```

- **Интерфейс** (`src/`): React + TypeScript. Только показ и ввод; данные проекта приходят из
  ядра, правки уходят командами. Предпросмотр кадра — плеер Remotion прямо в окне.
- **Ядро** (`src-tauri/`): Rust. Владеет файлом проекта (все правки — через сервис проекта с
  историей), запускает внешние программы, поднимает MCP-сервер для Claude.
- **Реестр команд** — общий для меню, горячих клавиш, контекстных меню, палитры команд и
  Claude (`docs/ui.md`). Команда описана один раз: имя, ключ перевода, иконка, клавиши, условие
  доступности, действие.
- **Claude** — внешняя программа `claude` (Claude Code CLI) пользователя, со своим входом и
  подпиской: чат — режим без окна с потоком событий, терминал — обычный интерактивный режим
  (`docs/claude-bridge.md`).
- **Рендер** — Remotion в среде Node.js (компонент): общая композиция «таймлайн» читает файл
  проекта; «умные клипы» (анимации кодом) — файлы проекта `smart/*.tsx`, собираются esbuild из
  того же Node.js (`docs/project-format.md`).
- **Медиа** — ffprobe (длительность, кодеки, звук), ffmpeg (миниатюры, волна звука, прокси для
  тяжелых файлов, обработка звука).

### Стек

| Часть | Выбор |
| --- | --- |
| Оболочка | Tauri 2, окно без системной рамки (своя строка заголовка с меню) |
| Интерфейс | React 19, TypeScript, Vite, Tailwind CSS 4 поверх своих токенов (`docs/design.md`) |
| Состояние | Zustand (интерфейс), данные проекта — из ядра |
| Типы команд | tauri-specta (Rust → TypeScript, без ручных описаний) |
| Панели | react-resizable-panels (раскладка рабочих областей, сохранение размеров) |
| Редактор текста | CodeMirror 6 (правила, сценарий, бриф — Markdown с подсветкой и предпросмотром) |
| Терминал | xterm.js (окно) + portable-pty (Rust, ConPTY) |
| Переводы | i18next (ru, en) |
| Иконки | lucide-react |
| Видео | Remotion (плеер в окне, рендер в Node.js) |
| Медиа | ffmpeg, ffprobe (компонент) |
| MCP | сервер в ядре по HTTP на 127.0.0.1 со случайным ключом на запуск |
| Журнал | tauri-plugin-log, файлы по группам |

| Указатель и учет | SQLite (rusqlite) в ядре, миграции по `PRAGMA user_version` |

Проект — самостоятельная папка (переносится и открывается без базы). SQLite приложения —
указатель и учет: недавние проекты, инструменты пользователя и их запуски, расход Claude по
проектам; настройки — JSON с версией.

### Раскладка репозитория

```
src/                    интерфейс
  app/                  окно, рабочие области, реестр команд, горячие клавиши
  pages/                Home/, Prepare/, Edit/, Export/, Settings/, Setup/
  panels/               Media/, Viewer/, Timeline/, Inspector/, Claude/, Terminal/, Rules/
  shared/               ui/ (кнопки, поля, меню, диалоги), i18n/, ipc/ (сгенерировано), lib/
src-tauri/src/
  project/              файл проекта, история, схема, миграции
  claude/               процесс claude, поток событий, сборка подсказки, сессии
  mcp/                  MCP-сервер студии и его инструменты
  terminal/             pty
  components/           установка и проверка компонентов
  media/                ffprobe, миниатюры, волна, прокси
  render/               очередь рендера, вызов движка
render/                 движок рендера: композиция «таймлайн», встроенные клипы (TS, Remotion)
design/mockups/         макеты
docs/                   документация
```

## Данные и хранение

| Что | Где |
| --- | --- |
| Настройки | `%APPDATA%\<app-id>\settings.json` |
| Указатель и учет (SQLite) | `%APPDATA%\<app-id>\studio.db`: `projects` (недавние, путь, формат, последнее открытие), `tools`, `tool_runs` ([extensions.md](extensions.md)), `claude_turns` (расход по проектам, [claude-bridge.md](claude-bridge.md)) |
| Компоненты | `%LOCALAPPDATA%\<app-id>\components\` (`docs/components.md`) |
| Журнал | `%LOCALAPPDATA%\<app-id>\logs\` |
| Библиотека (общие правила, стили, звуки, шаблоны) | `Документы\Montage Studio\Library\` — папки, видны пользователю |
| Проект | любая папка пользователя (`docs/project-format.md`) |

## Правила

- Интерфейс не держит своей копии проекта для правок: правка — команда в ядро, ядро
  присылает изменения (событие с новой версией таймлайна).
- Внешние программы — только из папки компонентов или найденные и проверенные (`claude`).
- Все длинные операции (установка, рендер, разбор медиа) — в фоне с ходом и отменой.
