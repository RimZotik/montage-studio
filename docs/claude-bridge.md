# Связь с Claude

Как приложение разговаривает с Claude Code: чат с разобранным потоком событий, терминал,
сборка подсказки из правил и выделения, инструменты студии через MCP.

## Назначение

Claude работает с проектом как второй монтажер: видит правила проекта, выделение на таймлайне и
файлы, правит проект только инструментами студии (с отменой), а ответы и действия показываются
в привычных панелях, а не простыней текста.

## Как устроено

### Два способа

- **Чат** (панель «Claude», основной): ядро запускает `claude` в папке проекта в режиме без окна —
  `-p --input-format stream-json --output-format stream-json --verbose --include-partial-messages`,
  плюс `--append-system-prompt-file`, `--mcp-config`, `--permission-mode`, `--resume <сессия>`.
  Процесс живет, пока открыт проект; сообщения пользователя уходят в его вход строками JSON,
  события читаются из выхода. Сессия сохраняется в проекте — разговор продолжается после
  перезапуска.
- **Терминал** (панель «Терминал»): обычный интерактивный `claude` (или оболочка) в pty в папке
  проекта — для всего, что удобнее руками. MCP студии подключен и там (`.mcp.json` проекта).

Флаги сверять с `claude --help` установленной версии; поддерживаемая версия — в манифесте
компонентов.

### Сборка подсказки

Каждое сообщение из чата = текст пользователя + **блок контекста**, собранный сервисом:

- выделение: клипы (дорожка, время, файл), точка воспроизведения, отмеченный диапазон;
- прикрепленное: файлы, перетащенные из медиа в чат, кадр предпросмотра (картинкой);
- быстрые действия — шаблоны сообщений с параметрами (кнопки над полем ввода: «Субтитры к
  выделенному», «Подогнать футаж под голос», «Проверить по правилам»; свои — в библиотеке).

**Постоянный контекст** — файл `--append-system-prompt-file`, собирается при открытии проекта и
при каждом изменении правил (процесс перезапускается с той же сессией):

1. базовые правила студии (как устроен проект, какими инструментами что делать, нельзя писать
   файл проекта напрямую);
2. включенные правила библиотеки (общие стили и привычки монтажа);
3. правила проекта: `rules/brief.md`, `rules/rules.md`, `rules/style.md`, `rules/script.md`;
4. настройки последовательности (размер, частота, безопасные зоны).

Правила — обычные Markdown-файлы: их правит пользователь в редакторе «Подготовки» и Claude
(своими инструментами или инструментом `rules.update`), изменения видны обоим.

### Разбор ответа

Поток событий раскладывается по панелям:

| Событие | Куда |
| --- | --- |
| текст ассистента (по частям) | сообщение в чате, Markdown, печатается по мере прихода |
| вызов инструмента студии (`timeline.*`, `captions.*`, `audio.*`) | карточка действия в чате («Добавлен клип V2 0:03.20–0:05.00»), подсветка на таймлайне, одна группа отмены на ответ |
| `render.frame` | кадр в чате, клик — точка воспроизведения |
| `ui.ask` | вопрос с кнопками вариантов в чате |
| `ui.notify` | уведомление в углу окна |
| встроенные инструменты Claude (чтение файлов, команды) | свернутая строка «Читает rules/style.md», раскрывается |
| запрос разрешения | диалог «Разрешить / Разрешить всегда для проекта / Запретить» (`--permission-prompt-tool` → инструмент MCP студии) |
| итог хода (стоимость, время, ошибки) | строка под ответом, ошибка — с кнопкой «Повторить» |

Пока Claude отвечает: кнопка «Остановить», ввод не блокируется (следующее сообщение ждет в
очереди). «Отменить изменения Claude» — одна команда на весь ход.

### MCP-сервер студии

Сервер в ядре, HTTP на 127.0.0.1, порт и ключ — новые на каждый запуск, записываются в
`.studio/mcp.json` проекта для обоих способов.

| Группа | Инструменты |
| --- | --- |
| проект | `project.read` (последовательность, дорожки, клипы), `project.settings` |
| таймлайн | `timeline.add_clip`, `move`, `trim`, `split`, `delete`, `set_props`, `add_keyframes`, `add_marker` |
| медиа | `media.list`, `media.probe`, `media.import` |
| субтитры | `captions.align` (по голосу, по словам и слогам), `captions.set` |
| звук | `audio.process_voice` (громкость, компрессия), `audio.sfx` (из библиотеки или синтез), `audio.music_bed` (подложка под таймлайн, приглушение под голос) |
| умные клипы | `smart.create`, `smart.update` (файл `smart/*.tsx` + параметры), `smart.build` |
| рендер | `render.frame` (кадр PNG, чтобы Claude посмотрел результат), `render.video` (в очередь) |
| правила | `rules.read`, `rules.update` |
| интерфейс | `ui.ask`, `ui.notify`, `ui.select` (выделить клипы), `ui.seek` |

Все правки таймлайна — через сервис проекта: проверка схемы, история, событие в интерфейс.

## Данные и хранение

`.studio/claude/` проекта: `session.json` (ID сессии, модель), `system.md` (собранный
постоянный контекст), история чата для показа (`chat.jsonl`). Модель и режим разрешений — в
настройках приложения, переопределяются в проекте.

## Правила

- Приложение не хранит ключи и вход Claude — только вызывает установленный `claude`.
- Claude меняет проект только инструментами студии; прямую запись `project.json` и
  `timeline.json` запрещают базовые правила и режим разрешений.
- Любое изменение от Claude отменяется одной командой.
