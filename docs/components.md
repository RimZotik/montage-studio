# Компоненты

Что приложение докачивает при первом запуске (как установщики программ докачивают нужные
среды) и как проверяет то, что ставит пользователь.

## Назначение

Установщик приложения — маленький; тяжелое (Node.js, движок рендера, ffmpeg) ставится отдельно,
с выбором, ходом загрузки и проверкой. Без компонента недоступны только зависящие от него
функции — приложение открывается всегда.

## Как устроено

| Компонент | Зачем | Откуда | Размер (порядок) |
| --- | --- | --- | --- |
| Claude Code CLI | чат и терминал с Claude | ставит пользователь (официальная установка); приложение находит `claude` в PATH или по пути из настроек, проверяет версию и вход | — |
| Node.js | среда движка рендера | официальный архив Windows x64 под закрепленную версию, проверка SHA-256 по опубликованным суммам | ~35 МБ |
| Движок рендера | сборка видео (Remotion), сборка умных клипов (esbuild), браузер для кадров (Chrome Headless Shell) | пакеты npm закрепленных версий в папку компонента (`npm ci` по своему lock-файлу), браузер — средствами Remotion | ~250 МБ |
| ffmpeg, ffprobe | медиа: свойства файлов, миниатюры, волна, прокси, звук | полная сборка для Windows закрепленной версии с проверкой суммы | ~90 МБ |

- **Манифест** — в коде приложения: версия, адрес, сумма, размер каждого компонента. Новая версия
  приложения может поднять версии компонентов — тогда предлагается обновление.
- **Первый запуск — экран «Компоненты»** (макет): список с состоянием («не установлен»,
  «загрузка 42 %», «готов», «нужна новая версия», «ошибка»), размером и назначением; «Установить
  все» и по одному; «Позже» — сразу на главную. Тот же экран — в настройках.
- **Загрузка**: в `components\<имя>\.part`, докачка после обрыва, проверка суммы, распаковка во
  временную папку, переключение одним переименованием (половинчатой установки не бывает).
- **Проверка при запуске** — быстрая (файлы на месте, версия); глубокая (запуск `--version`) —
  в фоне. Ошибка — значок в строке состояния и пункт «Компоненты» в меню «Справка».
- **Claude Code**: найден — версия и состояние входа (`claude` отвечает без ошибки входа); не
  найден — инструкция и кнопка «Открыть страницу установки», поле «Указать путь вручную»,
  «Проверить снова». Приложение не ставит Claude само и не хранит его ключи.
- **Железо**: при первом запуске — видеокарта, память, ядра; от них зависят настройки рендера
  по умолчанию (число потоков, аппаратное кодирование, прокси для тяжелых файлов).

## Данные и хранение

`%LOCALAPPDATA%\<app-id>\components\{node,render,ffmpeg}\` и `components.json` (`version`,
установленные версии и суммы). Удаление приложения — с вопросом, удалять ли компоненты.

## Правила

- Только закрепленные версии и проверка суммы: без суммы файл не запускается.
- Remotion бесплатен для частных лиц и небольших команд; для компаний нужна лицензия — сказать об
  этом на экране «Компоненты» и в «О программе».
- Компонент можно переустановить и удалить из настроек; удаление не трогает проекты.
