# Оформление

Светлый минималистичный интерфейс: белый с легким мандариновым градиентом, плотная компоновка,
никаких «окон в окнах». Образец — макет `design/mockups/home.html`.

## Назначение

Инструмент для долгой работы: ничего лишнего вокруг картинки и таймлайна, цвет — только там,
где он несет смысл (действие, выделение, тип дорожки, состояние).

## Как устроено

### Принципы

- **Жесткий минимализм.** Разделение — отступами и одной линией 1 px, не рамками и подложками.
  Нет карточек внутри панелей, фона на фоне, декоративных значков и плашек.
- **Компактность.** Строка 28 px, поле и кнопка 28 px, иконка-кнопка 24 px, шаг отступов 4.
  Места под контент — максимум.
- **Во весь экран.** Раскладка рассчитана на окно, развернутое на весь монитор (от 1366×768 до
  2560×1440 и выше): панели тянутся, а не стоят фиксированными коробками посередине.
- **Тени** — только у плавающего (меню, всплывающие панели, диалоги, уведомления).
- **Градиент** — один, фоновый: белый, переходящий в светлый мандарин в углу окна или под
  верхней панелью. Белого всегда больше, чем оранжевого.

### Цвета (светлая тема, по умолчанию)

| Токен | Значение | Где |
| --- | --- | --- |
| `--bg` | `#FFFFFF` | фон окна и панелей |
| `--bar` | `#FBF9F7` | верхняя системная строка, строка состояния |
| `--hover` | `#F5F1ED` | наведение, выбранная строка |
| `--line` | `#EDE8E3` | линии-разделители, границы полей |
| `--text` | `#1F1A17` | основной текст |
| `--muted` | `#7A716B` | подписи, второстепенное |
| `--faint` | `#B4ABA4` | неактивное, подсказки в полях |
| `--accent` | `#F28A4B` | мандарин: главная кнопка, фокус, выделение, точка воспроизведения |
| `--accent-ink` | `#C9581C` | мандариновый текст и иконки на белом (контраст) |
| `--accent-soft` | `#FFF2E9` | фон выбранного |
| `--grad` | `linear-gradient(135deg, #FFFFFF 55%, #FFF3EA 78%, #FFE1CC 100%)` | фон главной, полоса под второй строкой |
| `--ok` | `#2E9E68` | готово |
| `--warn` | `#D99A1E` | предупреждение |
| `--danger` | `#E5484D` | ошибка, удаление |

Дорожки (заливка клипа 14 %, полоса сверху 100 %): видео `#4F7CFF`, умные клипы `#9A6BFF`,
субтитры `#D9A514`, голос `#2E9E68`, музыка `#1FA2A2`, звуки `#F28A4B`.

Темная тема — те же токены с другими значениями (позже); компоненты знают только токены.

### Шрифты

- Интерфейс — Geist (400, 500, 600); таймкоды, числа, клавиши — Geist Mono. Шрифты внутри
  приложения, без загрузки из сети.
- Размеры: 11 (строка состояния, подписи), 12 (меню, панели), 13 (основной), 16 (заголовки
  разделов), 24 (заголовок главной).

### Элементы

- **Кнопки:** главная — заливка `--accent`, белый текст; обычная — белая с линией `--line`;
  тихая — только текст или иконка, наведение `--hover`. Нажатие — сжатие 0.97 за 80 мс.
- **Вкладки** второй строки — текст `--muted`, активная — `--text` и линия `--accent` 2 px
  снизу, без подложек.
- **Поля** — белые с линией `--line`, фокус — линия `--accent`; числовые тянутся мышью.
- **Меню** — белая панель, тень, пункт 28 px, клавиши справа `--faint` моно-шрифтом.
- **Списки и таблицы** — строки без рамок, разделитель — линия; наведение `--hover`.
- **Миниатюры** — скругление 6, без рамки; подпись под миниатюрой, не на подложке.
- **Индикатор лимитов Claude** — две тонкие полосы (сессия, неделя) с процентами,
  `--accent` до 80 %, `--warn` выше, `--danger` на пределе.
- Иконки — lucide-react, 16 px (14 в меню), линия 1.75; рядом с текстом — по центру по
  вертикали.

### Анимации

- Меню, подсказки, диалоги — 120–160 мс, прозрачность и сдвиг 4 px, `ease-out`.
- Переключение страниц и рабочих областей — без анимации раскладки.
- Ход операций — тонкие полосы 2 px.
- Без пружин и «прыгающих» эффектов.

## Данные и хранение

Токены — `src/shared/ui/tokens.css` (CSS-переменные), Tailwind читает их из темы.

## Правила

- Цвет — только токенами; новых цветов в компонентах не заводить.
- Перед новой подложкой или рамкой — проверить, нельзя ли обойтись отступом или линией.
