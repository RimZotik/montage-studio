# Оформление

Свои токены цвета, шрифты, размеры, элементы и анимации. Образцы — в макете
`design/mockups/studio.html`.

## Назначение

Спокойный темный интерфейс для долгой работы с картинкой: цвет — только там, где он несет смысл
(тип дорожки, выделение, состояние), все остальное — оттенки графита.

## Как устроено

### Цвета (темная тема, по умолчанию)

| Токен | Значение | Где |
| --- | --- | --- |
| `--bg` | `#0E1013` | фон окна, за панелями |
| `--panel` | `#15181D` | панели |
| `--raised` | `#1B1F25` | поля, кнопки, карточки |
| `--hover` | `#232831` | наведение |
| `--line` | `#262B33` | границы, разделители |
| `--text` | `#E8EBF0` | основной текст |
| `--muted` | `#8C95A4` | подписи, второстепенное |
| `--faint` | `#5A6270` | неактивное |
| `--accent` | `#8B7CFF` | выделение, фокус, главная кнопка, точка воспроизведения |
| `--accent-soft` | `rgba(139,124,255,.16)` | фон выделенного |
| `--ok` | `#3DDC97` | готово, успех |
| `--warn` | `#FFB547` | предупреждение |
| `--danger` | `#FF5C6C` | ошибка, удаление, запись |

Дорожки: видео `#5B8CFF`, умные клипы `#B07CFF`, субтитры `#F2D16B`, голос `#3DDC97`, музыка
`#2EC4C4`, звуки `#FF9F5A`. Клип — заливка цветом дорожки 22 %, полоса сверху 100 %, выделенный —
обводка `--accent` 2 px.

Светлая тема — те же токены, другие значения (позже); компоненты используют только токены.

### Шрифты и размеры

- Интерфейс — Geist (400, 500, 600), таймкоды и числа — Geist Mono (цифры одной ширины).
  Шрифты в пакете приложения, без загрузки из сети.
- Размеры: 11 (подписи дорожек, строка состояния), 12 (панели, меню), 13 (основной), 15
  (заголовки панелей на главной), 22 и 32 (заголовки главной).
- Плотность — как у профессиональных программ: строка меню 28, поле и кнопка 28, мелкая
  кнопка-иконка 24, высота дорожки видео 56, звука 48, субтитров 32 (тянется).
- Скругления: 4 (поля, клипы), 6 (кнопки, меню), 10 (карточки, диалоги).
- Отступы — шаг 4.

### Элементы

- **Кнопки**: главная (заливка `--accent`, текст темный), обычная (`--raised`, граница
  `--line`), тихая (без фона, наведение `--hover`), опасная (`--danger` контуром), иконка
  (квадрат 24/28). Нажатие — сжатие 0.97 за 80 мс.
- **Поля**: числовые поля тянутся мышью влево-вправо (изменение значения), колесо с Shift —
  точнее; таймкод — поле с масками кадров.
- **Меню и контекстные меню**: панель `--raised`, тень, пункт 28 px, клавиши справа `--muted`,
  разделители, подменю по наведению с задержкой 150 мс.
- **Вкладки панелей**: подпись 12, активная — текст `--text` и полоса `--accent` снизу 2 px.
- **Уведомления**: правый нижний угол, иконка по центру по вертикали слева от текста.
- **Подсказки**: по наведению 500 мс, название команды и клавиши.
- **Пустые состояния**: иконка, одна строка, действие («Перетащите файлы или нажмите Ctrl+I»).
- Иконки — lucide-react, 16 px в панелях, 14 в меню, линия 1.75; рядом с текстом — по центру
  по вертикали (flex, items-center, текст с плотной высотой строки).

### Анимации

- Появление меню, подсказок, диалогов — 120–160 мс, прозрачность и сдвиг 4 px, `ease-out`.
- Переключение рабочих областей — мгновенно (без анимации раскладки), панели не прыгают.
- Таймлайн: масштаб плавно к точке курсора, прокрутка инерционная; перетаскивание клипа —
  полупрозрачная копия и линия привязки `--accent`.
- Сообщения Claude: текст печатается по мере прихода, карточки действий вплывают 160 мс.
- Ход операций — тонкие полосы, без крутящихся колес там, где известен процент.
- Без пружинных и «прыгающих» эффектов в интерфейсе — это инструмент, не витрина.

### Главная

Единственное место с «витринным» фоном: еле заметная сетка кадров и мягкое пятно `--accent`
за заголовком; карточки проектов с кадром, при наведении — проигрывание превью без звука.

## Данные и хранение

Токены — `src/shared/ui/tokens.css` (CSS-переменные), Tailwind читает их из темы.

## Правила

- Цвет в компонентах — только токенами.
- Новый элемент — в `src/shared/ui/` и в макет, потом в страницы.
