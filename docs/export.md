# Экспорт

Готовый ролик: та же композиция, что играет в мониторе, рендерится движком и кодируется в файл,
который без вопросов принимают площадки.

## Назначение

Пользователь выбирает качество словами, а не настраивает кодек. Монтажным программам нужны сотни
параметров, потому что они отдают файлы в эфир, кино и производство; короткому ролику нужен один
правильный набор, остальное — вредные развилки. YouTube, TikTok и Instagram все равно перекодируют
загруженное, поэтому важен запас качества на входе, а не точный битрейт.

## Как устроено

| Качество | H.264 CRF | Звук AAC | Для чего |
| --- | --- | --- | --- |
| Для соцсетей (по умолчанию) | 18 | 256 кбит/с | Публикация |
| Максимальное | 15 | 320 кбит/с | Архив, дальнейший монтаж |
| Компактное | 23 | 160 кбит/с | Отправить на согласование |

CRF — постоянное качество: поток сам растет на сложных кадрах и падает на простых, поэтому файл не
больше нужного. Всегда: yuv420p (воспроизводится везде), BT.709 (цвета не плывут после загрузки),
звуковая дорожка есть даже у немого ролика, служебные данные в начале файла (`+faststart`: ролик
сразу начинает играть). Частота кадров и размер — из последовательности. H.265 — по выбору: файл
меньше, но подходит не везде (у него CRF выше на 5 при той же картинке).

- **Движок** (`components/render`): `@remotion/renderer` закрепленной версии (`npm ci` по файлу
  блокировки, с проверкой сумм) и браузер для кадров; ставится один раз со страницы «Экспорт».
- **Сборка композиции** (`resources/render-bundle`) готовится заранее
  (`scripts/build-render-bundle.mjs`) и идет с программой: пользователю не нужен сборщик.
- **Задание**: ядро запускает `resources/render/run.mjs` отдельным процессом; локальный сервер этого
  процесса отдает браузеру движка только `media/` проекта (с частичной отдачей). Ход — строками JSON
  → событие `ExportProgress`. При рендере кадры берутся точно из файла (`OffthreadVideo`), в
  мониторе — обычное видео браузера, поэтому предпросмотр не тормозит.
- **Claude**: `render_frame` (кадр картинкой, чтобы посмотреть результат), `export_start`,
  `export_status`.

### Быстродействие монитора

Экспорт всегда берет исходники. В мониторе тяжелый файл (длинная сторона больше 4K или поток выше 30
Мбит/с) играет через облегченную копию 720p с частыми опорными кадрами: она строится фоном, по одной,
в `.studio/cache/proxy/`. Таймлайн не перерисовывает клипы от движения головки и рисует только видимый
участок, поэтому сотни клипов не грузят воспроизведение.

## Данные и хранение

Готовые файлы — `output/` проекта, имена без повторов. Кадры для Claude —
`.studio/cache/frames/`. В проект ничего не записывается: экспорт не меняет историю.

## Правила

- Версия движка совпадает с версией `remotion` в интерфейсе (проверяет тест).
- После правки `src/render/*` — пересобрать сборку композиции (`npm run build:render`).
- Рендер отменяется снятием процесса, неполный файл удаляется.
