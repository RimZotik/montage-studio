# Библиотека: эффекты, инструменты, паки

Каталог всего, что используется в монтаже: эффекты на клипе, целые инструменты-пресеты (нарезка
под бит, вырезание пауз), стили роликов, звуки. Пользователь и Claude берут из нее готовое, Claude
пополняет ее по ходу работы и не изобретает одно и то же заново.

## Назначение

Повторяемые приемы не пересказываются Claude каждый раз и не собираются вручную: один раз описали
— дальше прием применяется одним действием, с настройками на своей панели и отменой одним шагом.
Для Claude это экономия токенов: вызов `tool_run` вместо десятков правок.

## Как устроено

### Паки на диске

`Документы\Montage Studio\Library\packs\<пак>\`:

- `main` — главный пак: все, что не входит в другие (сюда же ложатся новые элементы);
- `base` — базовый пак программы: только чтение, ставится и обновляется вместе с программой; чтобы
  поменять элемент, сохраняется копия. В нем только общие приемы (размытие, компрессор, вырезание
  пауз, субтитры по голосу); звуки, нарезка под бит и стили конкретных роликов — личное, в паки
  пользователя, с программой не идут;
- остальные — паки пользователя.

В папке пака: `pack.json` и `effects/<id>/effect.json`, `tools/<id>/tool.json`,
`styles/<id>/style.json`, `sounds/<id>/sound.json`. Элемент лежит в
одном паке, другие паки ссылаются на него по ID (`refs` в `pack.json`) — так один эффект входит в
несколько паков. `order` в `pack.json` — порядок, заданный пользователем; новые ссылки идут в конец. Архив пака (zip) содержит копии всего, в том числе добавленного из других паков.
При импорте: одинаковое становится ссылкой, другое с тем же ID получает новый ID. Удаление пака
переносит его элементы в главный, ничего не теряется. Прошлые версии элемента —
`<элемент>/.history/<правка>.json`.

### Эффект

Анимация свойств клипа данными, код не нужен:

```json
{ "id": "zoom-slow", "kind": "effect", "name": { "ru": "...", "en": "..." }, "description": { "ru": "...", "en": "..." },
  "targets": ["video"], "controls": [ ... ],
  "spec": { "tracks": [{ "prop": "scale", "anchor": "span", "keys": [[0, "$from"], [1, "$to"]], "ease": "linear" }] } }
```

- `targets` — значки назначения: `video`, `audio`, `text`, `sequence`, `transition`.
- `prop`: opacity, scale, x, y, rotate, blur, brightness, contrast, saturate, grayscale, sepia, hue,
  volume. Opacity, scale, volume, brightness, contrast, saturate перемножаются, остальные
  складываются. `spec.text` — цвет и плашка текста.
- `anchor`: `start` — время ключа в секундах от начала клипа; `end` — от конца (отрицательное);
  `span` — доля клипа 0–1; `none` — постоянное `value` или волна `wave: {amp, freq}`.
- Числа ключей — значения или выражения над панелью: `"$duration"`, `"-$duration"`, `"$to*2"`.

На клип кладется копия описания вместе со значениями (`clip.effects`): проект самостоятелен, правка
эффекта в библиотеке не меняет смонтированное. Разрез клипа убирает анимацию начала у правой части и
конца у левой.

### Инструмент

Правит таймлайн одним шагом отмены:

- `engine: "builtin"`, `builtin`: `beatCut` (удары в музыке → нарезка выбранных футажей и картинок),
  `removeSilence` (паузы в речи со сдвигом; связанная картинка и субтитры едут вместе),
  `captionsFromSpeech`, `normalize`, `duck`, `cutSounds` (звуки на склейках), `loopEnd` (начало уходит
  в конец: последний кадр подходит к первому), `blurBackground`, `audioProcess` (обработка звука новым
  файлом: цепочка `filter` с `$значениями` панели, например `highpass=f=$hp,loudnorm=I=$target`; в
  цепочке только фильтры из белого списка, читающих файлы среди них нет). Копия встроенного с другими
  значениями — новый пресет;
- `engine: "ops"`, `steps`: шаблон операций таймлайна с подстановками `$param`, `$clip.id`,
  `$clip.start`, `$clip.end`, `$clip.duration`, `$fps` и псевдооперацией `applyEffect`; `each:
  "selection"` — на каждый выбранный клип.

### Стиль и звук

- Стиль (`kind: "style"`, `rules`): правила для вида роликов — стадии, петля, переходы и звук, отступы.
  «Применить» кладет их своим блоком в `rules/style.md`, остальной текст файла не трогается; Claude
  следует им со следующего сообщения.
- Звук (`kind: "sound"`, `synth`, `seconds`, `hitAt`): синтезируется при первом использовании в
  `media/sfx/`; `hitAt` — где слышен удар, он и ставится на нужный кадр.

### Предпросмотр

Левая половина — как было, правая — как станет. Эффект показывается вживую по своему описанию на
сцене-образце (движение — при наведении, в открытой карточке — постоянно). Инструмент и звук — поле
`preview`: `{type:"wave", before, after}` (столбики громкости), `{type:"blocks", before, after}`
(длины кусков), `{type:"image", before, after}` (небольшие встроенные кадры `data:image`). Только
данные: чужой архив не несет файлов и адресов. Claude прикрепляет предпросмотр через `library_preview`.

### Панель управления

`controls` — свободный список, у каждого элемента своя панель; ее создает и меняет Claude (в том
числе по просьбе из чата) или пользователь, в коде ничего не зафиксировано:

`slider` (min, max, step, unit), `number`, `toggle`, `select` (options), `color`, `text`, `track`
(kinds), `section`, `note`; у всех — `label` (строка или `{ru, en}`), `help`, `default`,
`showIf: {id, eq}`, `half`. Незнакомый тип показывается простым полем: новые элементы панели не
ломают старые версии. Панель копируется на клип: можно поменять ее только у этого клипа.

### Интерфейс

- «Монтаж» → вкладка «Эффекты» слева: строки со значками назначения, поиск, фильтры. Один щелчок —
  послушать звук или открыть карточку; двойной — применить (звук — от головки, эффект — на выделенные
  клипы; без выделения — подсказка); перенос — на клип или дорожку, звук сразу показывает свою длину.
- Каталог (окно с той же страницы): паки слева, карточки с предпросмотром, правка имени и значений,
  порядок перетаскиванием, перенос на пак слева — добавить в его конец, удаление (кроме базового).
- «Свойства»: эффекты клипа с панелями, вкл/выкл, удалить, сохранить настройку в библиотеку.
- «Библиотека» на главной: паки, карточки со значками назначения, предпросмотр эффекта, копия,
  состав паков, архивы.

### Эффект на всю дорожку

`track.effects` действуют на каждый клип дорожки, в том числе будущие, анимация от начала и конца — у
каждого клипа своя. Щелчок по заголовку дорожки открывает ее панель: режим субтитров, эффекты дорожки и
эффекты, уже лежащие на клипах (одно изменение на все, перенос на дорожку). Эффект можно перетащить на
заголовок. Инструмент субтитров кладет оформление на дорожку, а не копию на каждый субтитр.

### Claude

В чате — короткий список библиотеки (ID и значения панели, частое первым), один раз на разговор и
после изменений. MCP: `library_list`, `library_get`, `library_save`, `pack_edit`, `effect_apply`,
`tool_run`; на клипе — операция `setEffect` (значения, панель, анимация). Придуманное в разговоре
Claude предлагает сохранить карточкой.

### Эффекты кодом (дальше)

Элементы с кодом (анимации на React, инструменты на TS) — следующий шаг, им нужна изоляция: чужой
архив не должен выполнять код с правами программы. Сейчас элемент — только данные, поэтому архив
безопасен: читаются лишь `pack.json`, `effect.json`, `tool.json`.

## Данные и хранение

- Файлы — папка библиотеки (видна пользователю, можно хранить в git).
- Учет использования — SQLite приложения, таблица `library_usage` (элемент, сколько раз, когда
  последний); состав библиотеки читается с диска, указателя нет.
- Базовый пак в программе: `src-tauri/resources/library/base-pack.json`; при правке содержимого —
  поднять `packVersion`.

## Правила

- Элемент проверяется при записи и чтении; поврежденный файл пропускается и не мешает остальным.
- Инструмент меняет проект только операциями через сервис проекта: один запуск — один шаг отмены.
- Клип хранит копию эффекта, а не ссылку.
- Инструмент отказывает, если таймлайн изменился за время его работы: план составлен по старым кадрам.
- Звук без картинки на видеодорожку и картинка на звуковую не ставятся (проверка при правке, не при
  чтении: старый проект открывается всегда).
