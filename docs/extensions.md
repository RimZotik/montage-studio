# Инструменты пользователя

Своя библиотека приемов монтажа: то, что придумал пользователь (например, «нарезать два футажа
по 2 секунды и чередовать»), Claude сохраняет как инструмент с названием и параметрами — потом
его запускают из меню, палитры команд или просят Claude применить.

## Назначение

Повторяемые приемы не пересказываются Claude каждый раз и не собираются вручную: один раз
описали — дальше инструмент делает то же самое быстро, одинаково и с отменой одним шагом.
Библиотека пополняется сама по ходу работы.

## Как устроено

### Инструмент

Папка в библиотеке `Library/tools/<id>/`:

- `tool.json` — `version`, `id`, название и описание (ru, en), параметры (JSON Schema: числа,
  выбор, дорожки, клипы, файлы), к чему применяется (выделенные клипы, дорожка,
  последовательность), автор (`user`, `claude`, позже `catalog`), версия инструмента.
- `run.ts` — функция `run(ctx, params)` на API студии: `ctx.selection()`, `ctx.timeline.*`
  (разрезать, переставить, добавить, свойства, ключи), `ctx.media.*` (свойства файлов),
  `ctx.ffmpeg` (обработка), `ctx.log`. Возвращает план правок, а не пишет файл сам.

Пример: «Нарезка с чередованием» — параметры «длина куска, с» (2), «клипы» (выделенные),
«порядок» (по очереди / случайно); результат — новые клипы на дорожке выделения.

### Запуск

- Код выполняется в Node.js из компонента «Движок рендера» отдельным процессом с ограниченным
  API (папка проекта, без сети).
- План правок проходит через сервис проекта: проверка схемы, предпросмотр изменений на таймлайне
  (призрачные клипы) с кнопками «Применить» и «Отмена», затем одна группа отмены.
- Откуда запускать: меню «Клип → Инструменты ›», контекстное меню клипа, палитра команд,
  Библиотека → Инструменты (форма параметров), Claude (инструмент MCP `tools.run`).

### Как пополняется

- В чате: пользователь описывает прием или говорит «сохрани это как инструмент» — Claude
  вызывает `tools.create` (пишет `tool.json` и `run.ts`, проверяет запуском на копии
  таймлайна), в чате — карточка «Новый инструмент: …» с кнопками «Открыть», «Запустить».
- Вручную: Библиотека → Инструменты → «Новый» (редактор кода и параметров).
- Правка — `tools.update` или редактор; прошлые версии сохраняются.

### Библиотека → Инструменты

Список: название, короткое описание, сколько раз запускали, когда последний раз, когда создан,
кто создал. Справа — описание, форма параметров, код, история запусков. Поиск, сортировка по
частоте и дате.

### Каталог (с 2.0)

Позже — серверный каталог инструментов, эффектов, умных клипов и шаблонов: установка в свою
библиотеку, обновления, публикация своих. Формат папки инструмента уже сейчас рассчитан на это
(`id`, версия, автор, хэш содержимого).

## Данные и хранение

- Файлы инструментов — `Library/tools/<id>/` (видны пользователю, можно хранить в git).
- Указатель и учет — SQLite приложения (`docs/architecture.md`): таблица `tools` (id, путь,
  название, описание, автор, создан, изменен, версия, хэш, источник), `tool_runs` (инструмент,
  проект, время, параметры, успех, длительность). Указатель пересобирается по папкам, если файлы
  поменяли вне приложения.

## Правила

- Инструмент не пишет файл проекта и не ходит в сеть — только возвращает план правок.
- Каждый запуск — одна группа отмены.
- Новый инструмент от Claude сначала проверяется запуском на копии таймлайна.
