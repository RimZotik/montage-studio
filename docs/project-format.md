# Формат проекта

Проект — папка; ролик целиком описан данными (последовательность, дорожки, клипы), сложные
анимации — файлами кода «умных клипов».

## Назначение

Один источник правды для интерфейса, Claude и рендера; папку можно перенести, сохранить в git
или открыть на другом ПК.

## Как устроено

```
<Проект>/
  project.json          имя, version, последовательность, включенные правила библиотеки
  timeline.json         дорожки и клипы
  rules/                brief.md, rules.md, style.md, script.md (Markdown)
  media/                footage/, voice/, music/, sfx/, images/ (структура — из шаблона)
  smart/                умные клипы: <имя>.tsx (компонент) + <имя>.json (параметры по умолчанию)
  output/               готовые ролики
  .studio/              служебное: history/, cache/ (миниатюры, волны, прокси), claude/, build/, mcp.json
  .gitignore            .studio/cache, .studio/build, output
```

### Последовательность

`width`, `height`, `fps`, `durationFrames` (или «по содержимому»), `background`, `safeArea`
(рамка под интерфейс площадок: пресеты «вертикальная площадка», «горизонтальное видео», свой),
`audio` (частота, целевая громкость LUFS).

Пресеты при создании: вертикальный 1080×1920, горизонтальный 1920×1080, квадрат 1080×1080,
частота 24/25/30/50/60.

### Таймлайн

```json
{
  "version": 1,
  "tracks": [
    { "id": "v2", "kind": "video", "name": "V2", "muted": false, "locked": false },
    { "id": "a1", "kind": "audio", "name": "Голос" },
    { "id": "s1", "kind": "captions", "name": "Субтитры" }
  ],
  "clips": [
    { "id": "c1", "track": "v2", "type": "media", "src": "media/footage/clip01.mp4",
      "start": 0, "in": 120, "out": 420, "props": { "scale": 1.1, "opacity": 1 },
      "keyframes": { "scale": [{ "f": 0, "v": 1 }, { "f": 60, "v": 1.1, "ease": "out" }] } },
    { "id": "c2", "track": "v3", "type": "smart", "component": "smart/TitleCard.tsx",
      "start": 300, "duration": 180, "params": { "title": "Глава 1", "accent": "#8B7CFF" } },
    { "id": "c3", "track": "s1", "type": "caption", "start": 30, "duration": 40,
      "text": "Смотри", "style": "pop-up" }
  ],
  "markers": [{ "f": 300, "label": "Удар", "color": "accent" }]
}
```

- Время — в кадрах последовательности (без дробных секунд в данных).
- Типы клипов: `media` (видео, картинка, звук), `smart` (компонент из `smart/`), `caption`,
  `solid` (заливка, фон), `adjustment` (эффект на дорожки ниже).
- Дорожки: `video` (чем выше, тем ближе к зрителю), `audio`, `captions`; у звука — громкость,
  приглушение под голос. Дорожка субтитров одна: стоит между видео и звуком, рисуется поверх всего
  видео; `captionMode`: `burned` (текст в кадре) или `file` (файлы рядом с роликом).
- Наложение на одной дорожке: верхний клип (позже в списке, перенос поднимает наверх) заменяет нижний
  на время наложения — и картинку, и звук, и текст субтитра. Нижний не обрезается: уберешь верхний —
  нижний снова целый.
- Свойства клипа: положение, масштаб, поворот, прозрачность, обрезка краев, скорость, громкость,
  переходы на входе и выходе; любое свойство — с ключами анимации.

### Умные клипы

Компонент React для Remotion с типизированными параметрами (схема в `<имя>.json`): камера с
пружиной, карточки, графики, заголовки — все, что удобнее описать кодом. Инспектор показывает
их параметры как обычные поля. Собирается esbuild из компонента «Движок рендера» в
`.studio/build/smart.js`; плеер в окне и рендер берут один и тот же файл.

### Шаблоны

Шаблон проекта = папка с `project.json`, `timeline.json` (с местами под данные), `rules/`,
`smart/` и структурой `media/`. «Сохранить как шаблон» — в библиотеку; новый проект из шаблона —
копия с подстановкой имени.

### Сервис проекта (`src-tauri/src/project/`)

Единственный, кто пишет `project.json` и `timeline.json`. Правка — команда ядра: копия
состояния меняется, проходит проверку (`model::validate`: имя, размер кадра 16–8192 и четный,
частота 1–240, цвет фона), записывается атомарно (временный файл + переименование, только
изменившийся файл) и становится шагом истории; интерфейс получает событие `ProjectChanged`.
Неверная правка отклоняется целиком. История (`history.rs`) — снимки «до/после», до 300 шагов,
отмена и повтор тоже записываются на диск; новая правка после отмены стирает ветку повтора.
Незнакомые сервису поля таймлайна (до 0.6) хранятся как есть и не теряются.

Команды: `project_load`, `project_close`, `project_current`, `project_set_sequence`,
`project_rename`, `project_undo`, `project_redo`, `timeline_apply`.

### Таймлайн сейчас (0.6, `project/timeline.rs`, `timeline.json` версии 2)

- Дорожки по умолчанию: V2, V1 (видео; выше — ближе к зрителю), S1 (субтитры), A1–A3 (звук).
- Клип: `id`, `track`, `kind` (`media` | `caption` | `solid`), `src` (`media/...`), `text`,
  `start`, `duration`, `offset` (обрезка начала файла) — в кадрах; `props`: `volume` 0–2,
  `opacity` 0–1, `scale`, `x`, `y`, `fadeIn`, `fadeOut` (кадров).
- Связка (`link`): видео со своим звуком (`addLinked` — клип картинки и клип звука одного файла);
  перенос, обрезка, разрез и удаление — вместе (разрез дает новую связку правым частям). Пока у
  видео есть связанный звук на включенной дорожке, картинка играет без звука.
- Наложение на одной дорожке разрешено и ничего не обрезает: верхний — позже в списке (перенос
  и обрезка поднимают клип наверх); звук нижнего под верхним не слышен. Сдвинули верхний —
  нижний снова виден целиком.
- Части одного файла встык, продолжающие друг друга в файле (после разреза), играются одним
  проигрывателем — без пауз и потерянных кадров; свойства частей применяются по кадрам.
- Правка — пакет операций `timeline_apply(ops, label)`: `addClip`, `addLinked`, `moveClip`, `trimClip`,
  `splitClip`, `deleteClips` (с `ripple`), `setProps`, `setText`, `setTrack`, `addTrack`,
  `removeTrack`, `duplicateClips`, `arrangeClips`, `setLink`, `addTrackEffect`, `setTrackEffect`,
  `removeTrackEffect`, `editWhere` (одна правка на все клипы по условию: дорожка, вид, файл, текст,
  участок, эффект), `addMarker`,
  `removeMarker`. Пакет применяется целиком или не применяется (закрепленная дорожка, неподходящий вид клипа — отказ), один шаг отмены. Этими же операциями
  будет править Claude (MCP студии).

## Данные и хранение

- `project.json`, `timeline.json` — `version`, миграция при открытии (старый файл — в
  `.studio/history/` перед записью новой версии); файл новее приложения не открывается
  (`newerProject`).
- История правок — в памяти, пока проект открыт (сохранение истории на диск для отмены после
  перезапуска — позже).
- Автосохранение — после каждой команды; запись атомарная (временный файл + переименование).

## Правила

- Пути к медиа — относительные внутри проекта; файл извне при импорте копируется в `media/`
  (`media.rs`): видео → `footage`, картинки → `images`, звук → `music` (от 45 с) или `sfx`;
  голос пользователь (или Claude) переносит сам — «Перенести в» в контекстном меню. Повтор имени
  — `clip-2.mp4`. Данные ffprobe и миниатюры (ffmpeg) — кэш `.studio/cache/` по пути, размеру и
  времени файла; имена файлов кэша — по SHA-256 ключа. В списке сразу — только готовое из кэша,
  недостающее (данные ffprobe, миниатюры, волны звука `showwavespic`) строится фоном, затем
  событие `MediaChanged`. Файл, занятый другой программой, при импорте пропускается с понятной
  причиной, остальные добавляются.
- Схема проверяется в ядре при каждой правке; ошибка — правка отклоняется целиком.
