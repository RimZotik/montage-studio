# Порядок работ

Версии 0.Y до 1.0; 1.0 — MVP, в котором целиком собирается короткий вертикальный ролик с
озвучкой, субтитрами, звуками, музыкой и анимациями кодом. Страницы развиваются по
необходимости: каждая версия добавляет то, без чего не обойтись на пути к 1.0.

## Назначение

Строить сначала основу (окно, команды, хранение, компоненты, Claude), потом монтажный стол — так,
чтобы ничего не переделывать, и проверять каждую версию в запущенном приложении.

## Как устроено

| Версия | Что входит |
| --- | --- |
| 0.1 | Каркас Tauri 2 + React + TS + Rust; токены оформления и базовые элементы; окно на весь экран: системная строка меню + вторая строка страницы + строка состояния; реестр команд, клавиши, палитра команд; ru/en; настройки; SQLite приложения; **главная** (начать, недавние проекты) |
| 0.2 | Компоненты: загрузка, проверка суммы, установка; экран «Компоненты»; проверка Claude Code |
| 0.3 | Проекты: создание, открытие, недавние; сервис проекта (схема, история, отмена, атомарная запись) |
| 0.4 | Claude: чат (поток событий, карточки действий, вопросы, разрешения, остановка), сборка контекста, лимиты и замеры расхода; терминал вторым способом |
| 0.5 | Подготовка: медиа (перетаскивание, ffprobe, миниатюры, волна), редактор правил проекта, настройки последовательности |
| 0.6 | Монтаж: таймлайн, предпросмотр, инспектор; MCP `timeline.*`, отмена изменений Claude |
| 0.7 | Звук, субтитры по голосу, умные клипы, `render.frame` |
| 0.8 | Экспорт и очередь рендера |
| 1.0 | MVP: ролик-образец собирается целиком в студии; установщик и обновления |
| 1.x | Инструменты пользователя (`docs/extensions.md`), шаблоны роликов, библиотека звуков и стилей, интерфейс пакетной обработки ffmpeg, превью и промты, темная тема |
| 2.0 | Серверный каталог инструментов, эффектов и шаблонов |

## Данные и хранение

Ход версий — в `CHANGELOG.md` с 0.1.

## Правила

- Следующая версия — только когда текущая проверена в запущенном приложении.
- Макет страницы — до ее кода; макеты делаются по одной странице, когда до нее дошла очередь.
