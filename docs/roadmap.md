# Порядок работ

Этапы от фундамента до первого ролика, собранного в студии. Каждый этап заканчивается рабочим
приложением, которое можно запустить и проверить.

## Назначение

Строить сначала основу (окно, команды, компоненты, проект, Claude), потом монтажный стол — так,
чтобы ничего не переделывать.

## Как устроено

### Этап 1. Фундамент

- Каркас Tauri 2 + Vite + React + TypeScript; Rust-ядро по папкам частей; tauri-specta;
  журнал; одна копия приложения.
- Токены оформления, шрифты, базовые элементы (`src/shared/ui/`): кнопки, поля, вкладки, меню,
  контекстное меню, диалог, уведомление, подсказка.
- Окно без рамки: строка заголовка с верхним меню, вкладки рабочих областей, строка состояния.
- Реестр команд, горячие клавиши, палитра команд, контекстные меню из реестра.
- Переводы ru/en.
- Настройки (`settings.json` с версией) и диалог настроек.
- Проверки: `cargo test`, clippy, typecheck, lint, тесты интерфейса; снимок окна.

### Этап 2. Компоненты

- Манифест, загрузка с докачкой, проверка суммы, установка одним переименованием.
- Экран «Компоненты» (первый запуск и настройки): Node.js, движок рендера, ffmpeg, проверка
  Claude Code CLI; железо ПК.

### Этап 3. Главная и проекты

- Главная (Главная · Проекты · Библиотека), новый проект (пресеты, шаблон, папки), открытие,
  недавние.
- Сервис проекта в Rust: `project.json`, `timeline.json`, схема, миграции, история и отмена,
  атомарная запись.

### Этап 4. Подготовка

- Медиа: перетаскивание, копирование в проект, разбор ffprobe, миниатюры и волна (ffmpeg).
- Редактор правил (CodeMirror): вкладки `rules/*.md`, правила библиотеки, ссылки `@media/...`.
- Настройки последовательности.

### Этап 5. Claude

- Терминал (xterm.js + pty) в папке проекта.
- Чат: процесс `claude` в режиме потока событий, сборка постоянного контекста и блока
  контекста, разбор событий по панелям, остановка, очередь, сессии.
- MCP-сервер студии: `project.*`, `rules.*`, `media.*`, `ui.*`; разрешения через свой диалог.

### Этап 6. Монтажный стол

- Таймлайн (дорожки, клипы, привязка, инструменты, масштаб), предпросмотр (плеер Remotion),
  инспектор, ключи анимации.
- Инструменты MCP `timeline.*`, «Отменить изменения Claude».

### Этап 7. Звук, субтитры, умные клипы, экспорт

- `audio.*`, `captions.align`, умные клипы (`smart.*`, сборка esbuild), `render.frame`.
- Экспорт и очередь рендера.
- Проверка этапа: ролик-образец целиком собирается в студии.

### Дальше

Шаблоны роликов, библиотека звуков и стилей, интерфейс пакетной обработки ffmpeg, превью и
промты к ним, светлая тема, установщик и обновления.

## Данные и хранение

Ход этапов — в `CHANGELOG.md` с первой версии.

## Правила

- Следующий этап — только когда текущий проверен в запущенном приложении.
