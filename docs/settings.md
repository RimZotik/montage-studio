# Настройки

Одно хранилище настроек программы: окно не хранит ничего своего, новой настройке нужен только ключ.

## Назначение

Все, что человек выбрал и ждет увидеть при следующем запуске: язык, модель, зона площадок, ширины
колонок, качество экспорта. Настройка не теряется при обновлении программы и не требует правки ядра.

## Как устроено

- **Ядро** (`src-tauri/src/settings.rs`) — источник правды, файл `settings.json` в папке данных
  программы. Типизированные поля — то, что читает само ядро (`language`, `projectsDir`, `claudeModel`).
  `ui` — словарь `область.имя` → значение: все настройки интерфейса.
- **Интерфейс** (`src/shared/settings/settings.ts`): читает до первого показа окна, поэтому панели сразу
  такие, как их оставили.

```ts
const [safe, setSafe] = useSetting("monitor.safeZone", true);
```

  Значение меняется сразу, запись идет пачкой через 250 мс (`settings_set_ui`), поэтому ползунок и
  граница колонки не пишут файл на каждое движение. `setSetting(key, null)` возвращает к умолчанию;
  значение по умолчанию живет в коде и в файл не попадает: его можно поменять в новой версии.
- **Окно** «Настройки» (Окно → Настройки, палитра команд): основное и сколько занимает кэш.

| Ключ | Что |
| --- | --- |
| `layout.<раскладка>` | ширины колонок |
| `monitor.safeZone`, `monitor.volume`, `monitor.muted` | монитор |
| `timeline.snap` | привязка |
| `edit.leftTab`, `effects.filter` | левая колонка «Монтажа» |
| `export.quality`, `export.codec`, `export.half` | экспорт |
| `chat.open` | чат открыт |

## Данные и хранение

`settings.json` с полем `version`; незнакомые поля и старые файлы читаются значениями по умолчанию.
Запись атомарная: через временный файл.

## Правила

- Новая настройка — новый ключ в `useSetting`, строка в таблице выше. `localStorage` для настроек не
  используется.
- Что относится к одному проекту, хранится в проекте (`storage.md`), а не здесь.
- Значение ключа не больше 64 КБ: это настройки, а не данные.
- `settings_update` не меняет `ui`: окно могло держать старую копию.
