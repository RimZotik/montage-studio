# Данные и кэш

Где что лежит и что можно удалить: одна карта для всей программы.

## Назначение

Работа пользователя не должна пропасть, а пересоздаваемое не должно мешать: данные и кэш разделены, и
код знает путь к кэшу только через один сервис.

## Как устроено

| Что | Где | Можно удалить |
| --- | --- | --- |
| Настройки | папка данных программы, `settings.json` (`settings.md`) | сбросятся |
| Недавние проекты, учет Claude, использование библиотеки | папка данных, `studio.db` (SQLite) | список и учет |
| Библиотека | `Документы\Montage Studio\Library` (`extensions.md`) | только свои паки: это работа |
| Проект | своя папка: `project.json`, `timeline.json`, `rules/`, `media/` | нет |
| Готовые ролики | выбранная папка или `output/`; список — `.studio/exports.json` (`export.md`) | сам файл |
| Кэш проекта | `.studio/cache/` | да |
| Кэш программы | папка кэша системы, `sounds/` | да |
| Компоненты | модель речи, движок рендера (`components.md`) | скачаются заново |
| Временные файлы рендера | папка из настроек «Временные файлы рендера» или временная папка системы, `montage-studio/render-temp/job-<время>/` (копии медиа движка на время сборки) | да; папка задания удаляется после рендера, оставшиеся старше 6 часов — при следующем рендере (`export.rs`, `run.mjs`) |

**Сервис кэша** (`src-tauri/src/cache.rs`): `cache::dir(проект, вид)`, `cache::app_dir(app, имя)`,
`cache_usage`, `cache_clear`; показан в окне «Настройки».

| Кэш | Что | Строится |
| --- | --- | --- |
| `thumbs` | миниатюры и волны | при открытии медиа |
| `proxy` | легкие копии для монитора | фоном, по одной |
| `speech` | расшифровка речи | при первом запросе (долго) |
| `frames` | кадры для Claude | по запросу; старше 7 дней убираются при открытии проекта |
| `sounds` | звуки библиотеки для прослушивания | при первом прослушивании |

### Легкие копии

Перемотка ждет декодирование от прошлого опорного кадра: в файле с редкими опорными кадрами это
заметные доли секунды, и дело не в мощности ПК. Поэтому копия 720p строится не только для тяжелых
файлов (больше 4K, выше 30 Мбит/с), но и когда опорные кадры реже чем раз в 0,75 с. Экспорт всегда берет
исходник. При перемотке мышью плееру уходит одна позиция за кадр экрана, головка движется сразу.

## Данные и хранение

У каждого формата на диске — поле `version` и чтение старых версий; SQLite — миграции по
`PRAGMA user_version`. `.gitignore` проекта исключает кэш и `output/`.

## Правила

- Путь к кэшу — только через `cache.rs`; строка `.studio/cache` в другом коде — ошибка.
- В кэше нет ничего, что нельзя построить заново.
- Запись данных — атомарная, через временный файл.
