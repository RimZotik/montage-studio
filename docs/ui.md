# Интерфейс

Окно, верхнее меню, рабочие области и страницы, панели, реестр команд, горячие клавиши и
контекстные меню. Макеты — `design/mockups/`.

## Назначение

Привычная логика монтажных программ: верхнее меню, рабочие области под этапы работы,
перестраиваемые панели, монтажный стол снизу, стандартные клавиши — чтобы человек, монтировавший
где угодно, сразу понимал, где что. Оформление и код — свои, минималистичные (`docs/design.md`).

**Схемы страниц ниже — ориентир.** Макет каждой страницы делается, когда до нее дошла очередь
(`docs/roadmap.md`), и может уточнить схему; готовый макет — `design/mockups/home.html`.

## Как устроено

### Окно

Рассчитано на весь экран (окно развернуто), без системной рамки.

```
┌ 1. Системная строка (30 px) ──────────────────────────────────────────────────────┐
│ [знак] Файл Правка Вид Окно Справка        Montage Studio — Промо      [─][□][×]  │
├ 2. Строка страницы (40 px) ───────────────────────────────────────────────────────┤
│ Подготовка  Монтаж  Экспорт │ Клип ▾ Последовательность ▾ │ … Сессия ▬ 33% Неделя ▬ 78% [Claude] │
├───────────────────────────────────────────────────────────────────────────────────┤
│                         рабочая область (панели)                                  │
├ Строка состояния (24 px) ─────────────────────────────────────────────────────────┤
│ Сохранено 12:04 · 1080×1920 60 к/с · Рендер: свободен · Компоненты: готовы · RU   │
└───────────────────────────────────────────────────────────────────────────────────┘
```

- **Первая строка — системная**, одинаковая везде: знак, стандартные меню (Файл, Правка, Вид,
  Окно, Справка), заголовок окна, кнопки окна. Перетаскивание окна, двойной клик — развернуть,
  привязка к краям экрана Windows.
- **Вторая строка — страницы:** слева навигация страницы (без проекта — «Главная · Проекты ·
  Библиотека», в проекте — «Подготовка · Монтаж · Экспорт»), затем меню и инструменты именно
  этой страницы (на «Монтаже» — «Клип ▾», «Последовательность ▾», инструменты таймлайна),
  справа — поиск страницы, индикатор лимитов Claude и главное действие страницы («Новый
  проект», «Экспорт»).
- **Без бокового меню.**
- Строка состояния: автосохранение, параметры последовательности, очередь рендера, состояние
  Claude и компонентов, язык; клик по пункту открывает связанное.

### Меню

Системная строка (всегда):

| Меню | Пункты |
| --- | --- |
| Файл | Новый проект, Открыть, Недавние ›, Импорт медиа, Сохранить как шаблон, Показать папку проекта, Закрыть проект, Настройки, Выход |
| Правка | Отменить, Повторить, Отменить изменения Claude, Вырезать, Копировать, Вставить, Вставить свойства, Удалить, Удалить со смыканием, Выделить все, Снять выделение, Палитра команд |
| Вид | Страницы ›, Сбросить раскладку, Безопасные зоны, Сетка, Масштаб предпросмотра ›, Тема ›, Язык › |
| Окно | Медиа, Предпросмотр, Таймлайн, Инспектор, Claude, Терминал, Правила, Очередь рендера, Журнал |
| Справка | Горячие клавиши, Компоненты, Открыть журнал, О программе |

Строка страницы (только там, где имеет смысл):

| Страница | Меню и инструменты |
| --- | --- |
| Подготовка | Проект ▾ (последовательность, правила, бриф, сценарий), импорт |
| Монтаж | Клип ▾ (разрезать, скорость, отключить, звук, ключ анимации, инструменты ›), Последовательность ▾ (дорожки, маркер, вход/выход, подогнать, привязка, кадр), инструменты таймлайна |
| Экспорт | пресет, диапазон, «В очередь» |
| везде в проекте | Claude ▾ (чат, новая сессия, быстрые действия, проверить по правилам, терминал, модель, разрешения) — рядом с индикатором лимитов |

Пункт меню показывает клавиши справа и серый, если команда сейчас недоступна.

### Реестр команд

Каждая команда — `id` (`timeline.split`), ключ перевода, иконка, клавиши по умолчанию, условие
(`when`: «есть выделение», «открыт проект»), действие. Из реестра строятся меню, контекстные
меню, подсказки кнопок, палитра команд (`Ctrl+Shift+P`, поиск по названию на обоих языках) и
список «Горячие клавиши» (переназначение — в настройках, конфликты подсвечиваются). Claude
может вызвать команду интерфейса через `ui.*`.

### Страницы

**Компоненты (первый запуск)** — приветствие и список компонентов с состоянием и размером,
«Установить все», «Позже» (`docs/components.md`).

**Главная** (без проекта; вкладки в строке заголовка):

- «Главная»: слева «Начать» (Новый проект, Открыть папку, Из шаблона), в центре — недавние
  проекты карточками (кадр, имя, формат 9:16 / 16:9, длительность, когда правился), справа —
  состояние компонентов и Claude, «Что нового».
- «Проекты»: таблица всех известных проектов (поиск, сортировка, формат, путь), действия —
  открыть, показать в папке, убрать из списка, сделать шаблоном.
- «Библиотека»: общие правила, стили субтитров, звуки, музыка, умные клипы, шаблоны проектов —
  слева разделы, в центре сетка или список, справа — просмотр и редактор (правила — Markdown,
  звук — волна и прослушивание).

**Новый проект** (диалог): имя, папка, пресет последовательности (карточки 9:16 / 16:9 / 1:1,
частота), шаблон (пустой, свои шаблоны), структура папок медиа (из шаблона, можно изменить).

**Подготовка** (рабочая область проекта):

```
┌ Медиа ─────────────┬ Правила проекта ──────────────────┬ Последовательность ┐
│ [Перетащите файлы] │ [Бриф][Правила][Стиль][Сценарий]  │ 1080×1920 · 60     │
│ Футаж  12          │                                   │ Длительность       │
│ Голос   2          │  Markdown-редактор                │ Безопасные зоны    │
│ Музыка  1          │  (подсветка, предпросмотр,        │ Фон, звук LUFS     │
│ Звуки   8          │   вставка ссылок на файлы @)      ├ Claude ────────────┤
│ Картинки 4         │                                   │ чат                │
└────────────────────┴───────────────────────────────────┴────────────────────┘
```

- Медиа: большая зона перетаскивания, разбор по папкам (по типу файла автоматически, можно
  переложить), карточки с кадром или волной, длительность, разрешение; двойной клик —
  предпросмотр; файлы можно тянуть в редактор правил и в чат (вставляется ссылка `@media/...`).
- Правила: вкладки-файлы `rules/*.md` + «Правила библиотеки» (галочки, какие общие правила
  включены). Сохранение — сразу; если файл поменял Claude, вкладка помечается и подсвечивает
  изменения.
- Последовательность: размеры, частота, длительность, безопасные зоны (рамка показывается в
  предпросмотре), фон, громкость.

**Монтаж** (основная):

```
┌ Медиа | Эффекты | Библиотека ┬──── Предпросмотр ────┬ Инспектор | Claude ┐
│                              │      кадр 9:16       │ свойства клипа или │
│                              │  ◀◀ ◀ ▶ ▶▶  00:03:20 │ чат                │
├──────────────────────────────┴──────────────────────┴────────────────────┤
│ [V][C][⇥]  00:00 ──── 00:05 ──── 00:10 ──── 00:15       масштаб ─○──      │
│ V3 Умные  ▓▓▓▓▓ TitleCard ▓▓                                           │
│ V2        ████ clip02 ████  ██ clip03 █                                  │
│ V1 Фон    ██████████████ background ████████████████                     │
│ S1 Субт.   ▫Смотри ▫сюда    ▫Глава ▫1                                   │
│ A1 Голос  ∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿∿                                        │
│ A2 Музыка ≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈                                │
│ A3 Звуки   ▪   ▪      ▪                                                  │
└──────────────────────────────────────────────────────────────────────────┘
```

- Таймлайн: заголовки дорожек (имя, выключить, закрепить, соло для звука), линейка с
  таймкодом, маркеры, зона входа и выхода, точка воспроизведения, волна звука, кадры на видео,
  привязка к краям клипов, маркерам, словам субтитров; инструменты «Выделение» (V), «Лезвие»
  (C), «Сдвиг со смыканием» (B); масштаб колесом с Ctrl и ползунком.
- Предпросмотр: кадр с рамкой безопасных зон, масштаб («по окну», 50 %, 100 %), транспорт,
  таймкод, полный экран; ручки положения и масштаба выделенного клипа прямо на кадре.
- Инспектор: свойства выделенного (положение, масштаб, поворот, прозрачность, скорость,
  громкость, переходы), ромбик ключа анимации у каждого свойства, параметры умного клипа.
- Claude — вкладкой рядом с инспектором или отдельной панелью (Вид → Рабочие области).

**Экспорт**: слева пресеты (вертикальная площадка, горизонтальное видео, своя), в центре —
предпросмотр и диапазон (вся последовательность / вход–выход), справа — кодек, качество,
битрейт, звук, папка и имя файла; снизу — очередь рендера (ход, оставшееся время, отмена,
«Показать файл»).

**Настройки** (диалог с разделами слева): Общие (язык, тема, автосохранение), Компоненты,
Claude (путь, модель, режим разрешений, быстрые действия), Горячие клавиши, Рендер (потоки,
аппаратное кодирование, прокси), Папки (библиотека, проекты по умолчанию).

### Подготовка сейчас (0.5.1)

Медиа | центр (Просмотр файла и вкладки правил) | проект и последовательность | Claude. Границы
колонок тянутся (двойной щелчок — ширина по умолчанию), ширины запоминаются. Перетаскивание
файлов в окно проекта — подсветка всего окна и надпись «Отпустите — файлы попадут в проект».
Щелчок по файлу медиа — «Просмотр»: видео и звук со своими кнопками (пробел, стрелки, повтор,
звук), у звука — волна с отметкой и переходом по щелчку, картинка — по размеру.

### Панели и рабочие области

- Панели перестраиваются: размеры тянутся, панели вкладками собираются вместе, любую можно
  открыть из меню «Окно»; раскладка сохраняется для каждой рабочей области. «Сбросить
  раскладку» возвращает исходную.
- Рабочие области переключаются `Alt+1/2/3`; Claude-чат открывается в любой (`Ctrl+L`).

### Горячие клавиши (по умолчанию)

| Клавиши | Действие |
| --- | --- |
| Пробел | воспроизведение / пауза |
| J / K / L | назад / стоп / вперед (повтор — быстрее) |
| ← / → | на кадр; с Shift — на 10 кадров |
| Home / End | в начало / в конец |
| I / O | вход / выход; Alt+I, Alt+O — сбросить |
| M | маркер |
| V / C / B | выделение / лезвие / сдвиг со смыканием |
| Ctrl+K | разрезать в точке воспроизведения |
| Q / W | обрезать начало / конец до точки со смыканием |
| Delete / Shift+Delete | удалить / удалить со смыканием |
| Ctrl+Z / Ctrl+Shift+Z | отменить / повторить |
| Ctrl+C / Ctrl+V / Ctrl+Alt+V | копировать / вставить / вставить свойства |
| + / − / \ | масштаб таймлайна / подогнать по окну |
| S | привязка вкл/выкл |
| Ctrl+S | сохранить (автосохранение и так включено) |
| Ctrl+I | импорт медиа |
| Ctrl+M | экспорт |
| Ctrl+L | чат Claude |
| Ctrl+` | терминал |
| Ctrl+Shift+P | палитра команд |
| Alt+1 / 2 / 3 | Подготовка / Монтаж / Экспорт |
| F11 | предпросмотр на весь экран |

В полях ввода и редакторе клавиши без модификаторов не перехватываются.

### Контекстные меню

Свои (не браузерные), из реестра команд: на клипе (разрезать, удалить, скорость, свойства,
«Спросить Claude про этот клип»), на дорожке, на пустом месте таймлайна, на файле медиа, на
сообщении Claude (копировать, повторить, отменить его изменения), во вкладке правил. Браузерное
меню отключено везде, кроме полей ввода (там — свое с копированием и вставкой).

### Языки

ru и en с первого экрана; язык — в настройках и меню «Вид», переключение без перезапуска.
Тексты — ключами `i18n/locales/{ru,en}.json`; длина подписей проверяется на обоих языках.

## Данные и хранение

Раскладки панелей, последняя рабочая область, масштаб таймлайна — в `settings.json`
(раскладки — общие, масштаб и область — для проекта в `.studio/ui.json`). Горячие клавиши
пользователя — `keybindings.json`.

## Правила

- Новое действие — сначала команда в реестре, потом кнопка или пункт меню.
- Любая длинная операция — с ходом в строке состояния и отменой.
- Ни одного текста в разметке без ключа перевода.
