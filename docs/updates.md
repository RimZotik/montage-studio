# Обновления и выпуск

Тихое автообновление приложения через обновлятор Tauri и порядок выпуска версии в GitHub
Releases.

## Назначение

Пользователь получает новую версию без мастеров установки: она скачивается в фоне, ставится
одной кнопкой (или командой меню) тихо, приложение запускается уже новым. Собственного
установщика и деинсталлятора пока нет — используется установщик NSIS от Tauri.

## Как устроено

### В приложении (`src-tauri/src/updates.rs`)

- Проверка через 8 с после запуска и затем раз в 30 мин; вручную — «Справка → Проверить
  обновления».
- Нашлась новая версия — установщик скачивается в фоне (ход — в строке состояния), затем во
  второй строке появляется «Обновить до X»; момент выбирает пользователь (может идти рендер).
- Установка — без окон (`plugins.updater.windows.installMode: quiet`), после нее приложение
  запускается новой версией.
- Подпись установщика проверяется открытым ключом из `tauri.conf.json`
  (`plugins.updater.pubkey`); чужой или поврежденный файл не ставится.
- Адрес — `https://github.com/RimZotik/montage-studio/releases/latest/download/latest.json`
  (репозиторий публичный).
- В разработке (`tauri dev`) выключено.

### Выпуск (`scripts/release.mjs`)

1. Поднять версию одинаково в `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`;
   записать изменения в `CHANGELOG.md`.
2. `node scripts/release.mjs --notes "Коротко, что нового"` — проверяет совпадение версий,
   собирает с подписью (`npm run tauri build`, ключ из переменных окружения), готовит
   `MontageStudio_<версия>_x64-setup.exe` и `latest.json` и публикует GitHub Release `v<версия>`
   (`gh`). `--dry` — только собрать и подготовить файлы в `src-tauri/target/release/publish/`.
3. Работающие приложения находят версию при следующей проверке.

## Данные и хранение

- Ключ подписи — **вне репозитория**: `%USERPROFILE%\.montage-studio\updater.key`,
  пароль — `updater.key.password`, открытый ключ — `updater.key.pub` (он же в
  `tauri.conf.json`). Потеря закрытого ключа = старые версии больше не примут обновления
  (придется ставить заново вручную); хранить копию в надежном месте.
- Скачанный установщик держится в памяти до установки или выхода.

## Правила

- Ключ и пароль не коммитить и не печатать в журнал и вывод.
- Версии в трех файлах всегда одинаковые (скрипт выпуска проверяет).
- Новая версия — новый тег `v<версия>`; переписывать выпущенную версию нельзя.
